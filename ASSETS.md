Нарисованы для проекта (свои, без сторонних лицензий):
- богатырь, Змей Горыныч (он же Ящер — без крыльев и с одной головой) и Тугарин — SVG в `public/assets/hero|dragon|tugarin/`;
- в `src/textures.ts` — трава, берёзы, ели, кусты, камни, пни, мухоморы, цветы, стог, плетень,
  камень на распутье, бревно, лужи нечисти, секира, копьё, гиря, молния, пирожок, сундуки,
  все иконки умений и 20 иконок предметов.

Исходники лежат в `raw-assets/`. `npm run assets` перекрашивает зомби, пакует атласы, декор и землю глав и копирует
эффекты и звуки в `public/assets/`.

Мягкие звуки (`raw-assets/sfx-soft/*.wav`) делает `tools/make-soft-sfx.mjs` из сэмплов в `raw-assets/sfx-src/`:
фильтр низких частот срезает резкий верх, хвост плавно гасится, громкость выравнивается.
Скрипту нужен браузер: `npm i --no-save puppeteer-core && node tools/make-soft-sfx.mjs`.
Рецепты (какой сэмпл, срез фильтра, громкость) — в начале скрипта, их удобно подкручивать. Папка `raw-assets/toon/` (старые персонажи Kenney) больше не используется.

## Указание авторов

CC BY и OGA-BY требуют указывать автора. В игре это строка титров в окне настроек (`src/ui/SettingsPanel.ts`, `CREDITS`):
«Нечисть: GameArt2D, sonild, Segel (CC0), CraftPix.net 2D Game Assets (OGA-BY 3.0). Земли: Drummyfish, rubberduck, pzUH,
Tio Aimar, Bevouliin (CC0), Dakal и Althaj (CC BY 3.0), LudicArts — Franco Giachetti (CC BY 4.0). Звуки: Kenney, qubodup, rubberduck (CC0)».
Добавляя ассет под CC BY / OGA-BY — допиши автора туда и в таблицу выше. NC, SA и GPL не берём.

## Как пересобрать спрайты глав

Мастер-копии уже лежат в `raw-assets/`, так что обычно достаточно `npm run assets`. Если нужно взять другие кадры:

1. Скачать паки из таблицы в одну папку (имена папок — как в `tools/mobs-manifest.mjs`, например `skeleton-warrior-sonild/files/...`).
2. `node tools/import-raw.mjs <папка> [id ...]` — выбирает кадры, разворачивает лицом вправо, совмещает анимации по ступням
   (холст симметричен относительно ступней — Phaser отражает кадр вокруг центра) и кладёт мастер-копии в `raw-assets/mobs`,
   декор — в `raw-assets/decor`, землю — в `raw-assets/ground`. С перечнем id обновляет только их.
3. `npm run assets` — атласы `public/assets/mobs/*` (по главам), `public/assets/decor/decor.*`, `public/assets/ground/*.png`
   и `src/gen/assets.ts`.
   Перекраска (Карачун, Вий, Пек, Ний, Чернобог) и контур скелетов делаются на этом шаге — их удобно подкручивать в манифесте.

# Богатырь против нечисти

Прототип игры для Яндекс Игр в духе Magic Survival: Phaser 4 + TypeScript + Vite.
Богатырь стоит в бесконечном лесу, со всех сторон лезет нечисть, иногда прилетает Змей Горыныч.
Бьёт богатырь сам, в основном вблизи. Игрок управляет движением и выбирает умения на каждом уровне.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка типов + сборка в dist/
npm run pack       # сборка + bogatyr-yandex.zip для загрузки в консоль Яндекс Игр
npm run assets     # пересобрать атлас зомби, эффекты, звуки и музыку из raw-assets/
```

Управление: WASD или стрелки на ПК, на телефоне плавающий джойстик (ведёшь пальцем по экрану).
Клавиши 1, 2, 3 выбирают карточку при повышении уровня. Esc или шестерёнка — настройки (пауза).

## Что есть

- **Опыт** начисляется сразу за убийство: душа нечисти улетает к богатырю. Кристаллов больше нет.
- **Оружие:** Меч-кладенец (стартовое), Вихрь секир, Богатырское копьё, Богатырский топот,
  Кистень (гиря на цепи, широкий круг), Соловьиный свист (конус с отбросом), Гнев Перуна (молнии).
- **Умения:** Живая вода (вампиризм, не больше 3,5% здоровья в секунду), Круговерть (как Counter Helix
  у Акса: при своём ударе или ударе по тебе — шанс крутануться и посечь всех вокруг; удар, на который
  ответил вихрем, не проходит; +10 к здоровью за уровень),
  Богатырская затрещина (крит), Щит Святогора (шанс блока), Медовуха (+опыт), Оберег (лечение в секунду),
  Кольчуга, Богатырское здоровье, Сапоги-скороходы, Сила богатырская, Удаль молодецкая, Размах плеча.
- **Враги:** Мертвяк, Кикимора (быстрая), Кощеев ратник (толстый), раз в минуту орда кольцом.
  **Боссы:** 3:00 Змей Горыныч, 5:00 Тугарин Змеевич (рывок и сабельный взмах с подсветкой на земле),
  7:30 Тугарин и Горыныч вместе, 10:00 Тугаро-Горыныч (огромный змей с Тугарином на спине, вдобавок
  огненный дождь), дальше по кругу каждые 2,5 минуты, по двое и крепче (`src/systems/Spawner.ts`).
  Змей Горыныч — медленный, толстый,
  дышит огнём конусом (перед выдохом конус подсвечивается на земле — можно увернуться),
  а если подойти вплотную — опускает все три головы и выдыхает огненное кольцо вокруг себя.
- **Сложность:** здоровье нечисти растёт только со временем (`src/systems/Spawner.ts`: `hpMul`), урон — со временем
  и немного с уровнем (`dmgMul`). Кощеевы ратники и боссы крепчают медленнее обычной нечисти.
  Со временем нечисть всё хуже отлетает от ударов, а после толчка ненадолго «устаёт» отлетать
  (`damageZombie` в `GameScene.ts`) — иначе стену из секир и топота не пробить.
  Волны идут ритмом (цикл 60 с): натиск → нарастание → орда дугой с проходом на 46-й секунде → затишье 10 с.
  Нечисти немного, но она крепкая; после удара богатырь 0,4 с неуязвим; когда здоровья меньше половины,
  нечисть прибывает реже — чтобы ближник мог вырваться из толпы.
- **Сундуки** раз в 100–140 с (первый ~1:10) появляются в лесу (к ближайшему показывает стрелка у края экрана),
  с первого убитого Змея Горыныча каждого прилёта падает сундук с дивным или былинным предметом. 20 уникальных предметов
  (`src/items.ts`) четырёх редкостей: Обычное, Редкое, Дивное (эпик), Былинное (легендарка).
  Например, Секира Ярой сечи (рассечение, как Battle Fury), Осколок Месяца (Moon Shard),
  Перо Жар-птицы (воскрешает один раз, как Aegis), Перстень Громовержца (цепная молния, как Mjollnir),
  Палица Ильи Муромца (крит, как Daedalus), Сердце Тура, Камень Алатырь, Шапка Мономаха, Гусли-самогуды.
- **Настройки:** громкость музыки и звуков, выбор трека. Сохраняются в localStorage.
- Смерть, воскрешение за рекламу (один раз за забег), рестарт с полноэкранной рекламой.
- Адаптив под ПК и телефон, портрет и ландшафт, чёткая картинка на HiDPI (мипмапы, текстуры ×2).

## Графика

- Богатырь и Змей Горыныч — векторные (SVG в `public/assets/hero/` и `public/assets/dragon/`),
  собираются в скелет и анимируются кодом (`src/entities/HeroRig.ts`, `src/entities/Dragon.ts`).
  При загрузке SVG растеризуются под разрешение экрана и пакуются в одну текстуру.
- Зомби — спрайты GameArt2D, перекрашенные под Русь (`tools/zombie-recolor.mjs`) и упакованные в атлас.
- Лес, предметы, иконки — процедурные (`src/textures.ts`).

## Музыка

Сейчас один трек — драм-н-бейс «Dark Ritual» (Of Far Different Nature, CC BY 4.0).
Треки лежат в `raw-assets/music/` + список `tracks.json`; если треков больше одного, в настройках появляется
переключатель. В игре грузится только выбранный трек (лениво, после меню). Добавить свой: положить mp3 в `raw-assets/music/`, дописать запись в `tracks.json`
(автор и лицензия — обязательно, нужна разрешающая коммерческое использование), затем `npm run assets`.

## Яндекс Игры

`src/yandex.ts` — обёртка SDK:
- на localhost SDK не грузится, вызовы работают как заглушки (реклама за награду сразу «досмотрена»);
- на хостинге Яндекса подгружается `/sdk.js`;
- `LoadingAPI.ready()` вызывается на титульном экране;
- `GameplayAPI.start/stop()` вызываются при паузах (выбор умения, настройки, смерть);
- на время рекламы звук глушится.

Загружать нужно `bogatyr-yandex.zip`: в его корне лежит `index.html`, пути относительные (`base: './'`).

## Структура

```
src/
  main.ts              конфиг Phaser, HiDPI, ресайз
  config.ts            баланс: герой, зомби
  settings.ts          громкость и трек (localStorage)
  music.ts             фоновая музыка, ленивая загрузка
  yandex.ts            Yandex Games SDK
  textures.ts          процедурная графика (лес, оружие, иконки)
  scenes/              Boot → Menu → Game + UI (HUD поверх)
  entities/            HeroRig/Player, Zombie, Dragon, Pickups
  abilities/           defs.ts (каталог умений), weapons.ts (логика оружия)
  systems/             Spawner (волны, сложность, Горыныч), SpatialGrid, Fx, Decor
  ui/SettingsPanel.ts  окно настроек
tools/
  build-assets.mjs     сборка ассетов, zombie-recolor.mjs — перекраска, pack.mjs — zip для Яндекса
```

Новое умение добавляется в `abilities/defs.ts`. Для оружия рядом пишется класс в `weapons.ts`.

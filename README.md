# Богатырь против нечисти

Прототип игры для Яндекс Игр в духе Magic Survival: Phaser 4 + TypeScript + Vite.
Богатырь пробивается через шесть глав — от Дремучего леса до Дна Пекла. Со всех сторон лезет нечисть,
в каждой главе по очереди приходят 3–4 босса. Бьёт богатырь сам, в основном вблизи. Игрок управляет
движением и выбирает умения на каждом уровне.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 (режим тестера включён)
npm run build      # проверка типов + сборка в dist/
npm run pack       # сборка + bogatyr-yandex.zip для загрузки в консоль Яндекс Игр
npm run assets     # пересобрать атласы, декор, землю, эффекты и звуки из raw-assets/
```

Управление: WASD или стрелки на ПК, на телефоне плавающий джойстик (ведёшь пальцем по экрану).
Клавиши 1, 2, 3 выбирают карточку при повышении уровня. Esc или шестерёнка — пауза: громкость,
«Продолжить», «В главное меню» (со второго нажатия, злато за пройденное начисляется).

**Режим тестера** — в `npm run dev` или на любом хосте с `?debug=1` в адресе; F2 прячет панель.
Кнопки: +1/+5 уровней, все умения на максимум, ускорение ×2/×4/×8, бессмертие, +1 минута,
босс сейчас, следующая глава, убить всех, сундук. В консоли браузера есть `dbg` (нечисть, боссы, главы).

## Что есть

- **Опыт** начисляется сразу за убийство: душа нечисти улетает к богатырю.
- **Оружие:** Меч-кладенец (стартовое), Вихрь секир, Богатырское копьё, Богатырский топот,
  Кистень, Соловьиный свист, Гнев Перуна. **Умения:** Живая вода, Круговерть, Богатырская затрещина,
  Щит Святогора, Медовуха, Оберег, Кольчуга и другие (`src/abilities/defs.ts`).
- **Главы** (`src/biomes.ts`) — своя земля, декор, «настроение», частицы, нечисть и боссы.
  Боссы приходят по очереди: первый через 3 минуты после начала главы, следующий — через 2 минуты
  после смерти предыдущего; после последнего — переход в следующую главу. После Дна Пекла —
  снова лес, но новый круг (всё вдвое крепче).

  | Глава | Нечисть | Боссы |
  |---|---|---|
  | I. Дремучий лес | мертвяки, кикиморы, кощеевы ратники, серые волки | Змей Горыныч → Тугарин Змеевич → **Тугаро-Горыныч** → Леший |
  | II. Темнолесье | костяные ратники и лучники, упыри, мертвяки | Кощей Бессмертный → Соловей-Разбойник → **Кощей-Соловей** |
  | III. Выжженная земля | разбойники, волки, упыри, чернокнижники | Волколак → Чёрный Колдун → **Волколдун** |
  | IV. Лютые морозы | мёрзлые мертвяки, навки, навьи стражи, снежные волки | Карачун → Лихо Одноглазое → **Лихой Карачун** |
  | V. Пекло | бесы, чертенята, грешные души, рогачи | Анчутка Беспятый → Вий → **Вий Неусыпный** → Пек, пекельный царь |
  | VI. Дно Пекла | грешные души, бесы, чертенята, упыри, рогачи | Ящер → Ний, владыка Нави → Чернобог |

  Третий босс главы — гибрид двух предыдущих: один сидит верхом на другом и пользуется приёмами обоих.
- **Боссы на спрайтах** собраны из приёмов (`src/bosses.ts`): удар сектором, удар оземь, прыжок, рывок,
  призыв нечисти, корни/лёд под ногами (опутывают), залп и кольцо снарядов, мгновенный перенос,
  огненный дождь, луч-взгляд (Лихо, Вий), свист с оглушением (Соловей), подкоп (Ящер),
  Печать Нави (лечение не действует), костяная клетка, стужа вокруг (замедляет). Любой приём сначала
  подсвечивается на земле — от него можно уйти. Кощей встаёт один раз после смерти, Чернобог
  на трети здоровья зовёт Тугарина и Тугаро-Горыныча. Логика — `src/systems/Bosses.ts`.
- **Сложность** (`src/systems/Spawner.ts`): здоровье и урон нечисти растут с «минутами угрозы» — это время забега,
  но не меньше ожидаемого для главы (кто пробежал главы быстро, слабых врагов там не встретит). Урон к поздним главам
  растёт всё быстрее. Первую минуту нечисть слабее (с 55% до нормы) — мягкий старт.
  С Выжженной земли изредка приходят **лютые** (красный круг под ногами): в 8 раз толще, бьют вдвое, почти не отлетают.
  В поздних главах есть стрелки (ледяные лучники, блуждающие и навьи огни). Броня — не больше 60%.
- **Богатырские удары боссов:** любой подсвеченный приём (и огонь Горыныча, и взмах Тугарина) нельзя отбить щитом
  или круговертью и от него не увернуться шапкой; броня держит вдвое хуже; урон — не меньше доли здоровья богатыря
  (в лесу ~45% от полной доли, на Дне Пекла — вся: удар оземь Чернобога ≈ треть здоровья). От них надо уходить.
  Здоровье боссов растёт мягче, чем у нечисти (`bossHpMul`), а приёмы в поздних главах перезаряжаются быстрее.
  Волны идут ритмом: натиск → нарастание → орда дугой с проходом → затишье. После удара богатырь 0,4 с неуязвим;
  когда здоровья меньше половины, нечисть прибывает реже.
- **Сундуки** раз в 100–140 с, с первого убитого босса каждого прилёта — дивный или былинный предмет.
  20 предметов четырёх редкостей (`src/items.ts`).
- **Мета-прокачка:** за забег — злато (за время, нечисть, боссов, главы), в меню — Древо талантов
  (3 ветви по 3 таланта, `src/talents.ts`). Сохраняется в облако Яндекса (для вошедших) и в браузер.
- Смерть, воскрешение за рекламу (раз за забег), рестарт с полноэкранной рекламой, выход в меню.
- Адаптив под ПК и телефон, портрет и ландшафт, чёткая картинка на HiDPI (мипмапы, текстуры ×2).

## Графика

- Богатырь, Змей Горыныч, Тугарин и Ящер — векторные (SVG в `public/assets/hero|dragon|tugarin/`),
  собираются в скелет и анимируются кодом (`src/entities/HeroRig.ts`, `Dragon.ts`).
- Зомби — спрайты GameArt2D, перекрашенные под Русь (`tools/zombie-recolor.mjs`).
- Нечисть и боссы глав II–VI, декор и земля — готовые спрайты и текстуры (см. `ASSETS.md`).
  `tools/import-raw.mjs` один раз забирает нужные кадры из скачанных паков в `raw-assets/mobs`
  (разворачивает лицом вправо, совмещает анимации по ступням), `tools/mobs-manifest.mjs` — что брать
  и как перекрасить, `tools/build-mobs.mjs` — атласы глав, декор, земля и `src/gen/assets.ts`.
- Атласы глав (`public/assets/mobs/`) грузятся фоном и выгружаются, когда глава позади
  (`src/mobs.ts`), — в видеопамяти одновременно лежат только текущая и следующая глава.
- Лес первой главы, предметы, иконки — процедурные (`src/textures.ts`).

Музыки нет (выпилена по просьбе). Звуки — `src/sfx.ts`, громкость — в настройках.

## Яндекс Игры

`src/yandex.ts` — обёртка SDK:
- на localhost SDK не грузится, вызовы работают как заглушки (реклама за награду сразу «досмотрена»);
- на хостинге Яндекса подгружается `/sdk.js`;
- `LoadingAPI.ready()` вызывается на титульном экране;
- `GameplayAPI.start/stop()` — при паузах (выбор умения, настройки, сундук, смерть);
- сохранения: `player.getData/setData` (облако), для гостей — localStorage (`src/save.ts`);
- на время рекламы звук глушится.

Загружать нужно `bogatyr-yandex.zip`: в его корне лежит `index.html`, пути относительные (`base: './'`).

## Структура

```
src/
  main.ts              конфиг Phaser, HiDPI, ресайз
  config.ts            баланс героя и нечисти (ZOMBIES)
  biomes.ts            главы: земля, декор, нечисть, боссы
  bosses.ts            боссы на спрайтах: облик, здоровье, приёмы
  mobs.ts              фоновая загрузка/выгрузка атласов глав, анимации
  items.ts, talents.ts предметы из сундуков, древо талантов
  save.ts, settings.ts сохранение прогресса и громкости
  yandex.ts            Yandex Games SDK
  debug.ts             режим тестера
  textures.ts          процедурная графика (лес, оружие, иконки)
  gen/assets.ts        сгенерировано сборкой: точки опоры, кадры, масштабы
  scenes/              Boot → Menu → Game + UI (HUD поверх)
  entities/            HeroRig/Player, Zombie, Dragon, Tugarin, SpriteBoss (+ Ящер), Pickups
  abilities/           defs.ts (каталог умений), weapons.ts (логика оружия)
  systems/             Spawner (волны, сложность, очередь боссов), Bosses (приёмы), Projectiles,
                       SpatialGrid, Fx, Decor
  ui/                  SettingsPanel, TalentPanel, DebugPanel
tools/
  build-assets.mjs     сборка всех ассетов; build-mobs.mjs, import-raw.mjs, mobs-manifest.mjs, img.mjs
  zombie-recolor.mjs   перекраска зомби; make-soft-sfx.mjs — мягкие звуки; pack.mjs — zip для Яндекса
```

Новое умение — в `abilities/defs.ts` (оружие — класс рядом в `weapons.ts`).
Новый босс — запись в `bosses.ts` (облик + список приёмов) и его вид в очереди главы в `biomes.ts`.
